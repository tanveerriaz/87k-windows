## Capture notes

- Record UI at native scale; avoid digital zoom that softens text.
- Capture each UI state with five seconds of handles before and after the intended action.
- Record Wall, Join and Admin separately. Synchronize in editorial on the approval event rather than filming multiple devices in one camera frame.
- Keep the pointer hidden unless it demonstrates a control. Use no decorative pointer circles.
- If the photographic redesign is still changing, wait for the reviewed visual build before recording final UI takes.
